# FDIC Bank Failure Early Warning System

## 1. Project Overview

This project aims to develop a Big Data Pipeline
for an early-warning system for bank failures
using publicly available FDIC data.

## 2. Project Objectives

- Acquire public FDIC data.
- Evaluate data storage formats.
- Conduct data quality assessment.
- Process data using Polars and PySpark.
- Develop financial features.
- Build and evaluate an early-warning model.
